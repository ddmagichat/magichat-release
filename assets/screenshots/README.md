# Screenshots

Place the screenshots referenced by the repository README in this directory.

| File | Content |
| --- | --- |
| `command-workspace.png` | A representative command workspace with reusable commands. |
| `task-center.png` | The task center with representative tasks or templates. |
| `Tools.png` | The tools window. |

Use PNG images with a consistent window size. A width between 1440 and 1920 pixels is recommended. Before committing a screenshot, remove usernames, private paths, tokens, command output, and other sensitive information.
